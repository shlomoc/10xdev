# Feedback & Maintenance

## Purpose
Collect user feedback and implement iterative improvements.

## Input
* Deployed application
* User feedback

## Steps

### 1. Give the collected feedback to your coding agent (Claude Code or Codex)
### 2. Ask it to create `maintenance-log.md` with root causes + fixes
### 3. Break it down, one item at a time
### 4. Ask your coding agent to fix each item, verify the fix, and check it off
### 5. Review the final commits with a separate review pass or a tool such as CodeRabbit

## Output
* `maintenance-log.md` - Ongoing maintenance documentation
* Updated roadmap for future development
